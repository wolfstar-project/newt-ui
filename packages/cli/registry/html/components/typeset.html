Threads

A thread keeps a side conversation out of the channel it started in, and disappears from the list once it goes quiet. Anyone who can read the parent channel can read the thread1. The name is bold in the list, an archived one is struck through, and every member can still search it.

Starting one

Hover a message and choose Create Thread, or use the composer's thread button to start one that is not attached to anything.

  • Public threads inherit the channel's permissions.
  • Private threads are invite-only, and do not appear in the list.
  • An archived thread reopens the moment somebody posts in it.

A thread archived after inactivity is not deleted.

Its history stays searchable, and the first new message brings it back — a quote holds as many paragraphs as it was given.

In code

The type field is what tells the two apart:

await channel.threads.create({
  name: "release-notes",
  type: ChannelType.PublicThread,
})
Type Visible to Archives after
Public Everyone in the channel 24 hours
Private Invited members 72 hours
