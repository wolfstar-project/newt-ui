# Trademark and copy

newt/ui is an independent, community-built project. It is **visually inspired
by** Discord's client design and is **not affiliated with, endorsed by, or
sponsored by Discord Inc.** Every component, page and example inherits those
terms.

## Never

- Reproduce Discord's logo, wordmark, Clyde mascot, or any icon from the client.
  No SVG copies, no CDN links, no base64. Every glyph in the registry is drawn
  for it.
- Generate a Discord asset because one is missing. Draw a neutral one, or use a
  component that already has a glyph.
- Use real Discord usernames, avatars, server names or invite links in an
  example. Placeholder data only.
