## Installation

```bash
npx @newtui/vue@latest add divider
```

## Usage

```vue
<script setup lang="ts">
import { Divider } from "@/components/ui/divider"
</script>

<template>
  <Divider>SECTION LABEL</Divider>
</template>
```
