A reply preview keeps the referenced author and excerpt attached to the message that answers it. Compose the avatar, author, text, action and command parts so the compact row still reflects the content being referenced.

## In a message group [#message-group]

Put the preview in `MessageGroupReply`. There it has no margin and no start padding, and the row sets the distance to the author line. Its spine starts above the centre of the avatar and stops 4px before the preview.

The spine reads [two custom properties](/docs/components/message-group#custom-properties) of the row: `--newt-message-group-avatar-size` and `--newt-message-group-gap`. If the row does not set them, the spine uses `40px` and `16px`. Outside a group, the preview keeps its own elbow, its margin and its padding.

In the plain HTML and CSS distribution, give the icon the class `newt-reply__command-icon` and put it before `newt-reply__command-name`. For an avatar with no image, use a `<span>` with the classes `newt-reply__avatar newt-reply__avatar--fallback` and put the icon in it.

The registry also exports `ReplyPreviewAvatar`, `ReplyPreviewAuthor`, `ReplyPreviewText`, `ReplyPreviewAction` and `ReplyPreviewCommand`. Each part accepts the native attributes of the element it renders.

## Accessibility

The avatar is decorative by default; provide alternative text only when it adds information that the adjacent author name does not. Keep the referenced text in DOM order, and use a real button or link outside the preview when the row itself opens the original message.
