The frame of a settings area, assembled from a [Side Nav](/docs/components/side-nav) and a [Breadcrumb](/docs/components/breadcrumb). You describe the sections as data and render the current one as the block's content, so each section stays an ordinary component of yours.

Below 40rem the navigation moves above the content.

The entries are buttons, because the block swaps content in place. In a routed app, copy the block and give each `SideNavItem` an `href`.

## Accessibility

The navigation is a landmark named by `title`. The content column is a plain box, so put the block inside your page's own `<main>`. The current section carries `aria-current="page"` in the navigation and is repeated as the breadcrumb's last crumb and as the heading above the content.
