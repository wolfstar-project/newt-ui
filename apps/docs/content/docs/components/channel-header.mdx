The bar above the message list, with the channel name, topic and channel actions. Compose it from the exported registry parts so local content and behaviour stay in the application while the visual contract stays token-driven.

## Usage

<Usage name="channel-header" />

Put the name and the topic in `ChannelHeaderInfo`, and the actions in `ChannelHeaderToolbar`. When the bar runs out of room, the topic shrinks first. The name truncates only after the topic has no width left.

## Examples

### Narrow layout

On a narrow screen, the bar holds three controls. `ChannelHeaderBack` leaves the channel and shows the unread count in `badge`. `ChannelHeaderTitle` makes the name a button that opens the channel details. `ChannelHeaderSearch` with `compact` draws only the icon. `ChannelHeaderOnline` shows the member count.

<ComponentPreview name="channel-header" variant="narrow" />

The bar has a minimum height, so a title with two lines makes it taller. Show one layout or the other with your own breakpoint classes.

### Decorative actions

A showcase or a read-only view draws the actions and does nothing with them. Pass `as="span"` to an action or to the search. The part keeps its look and loses its pointer, its hover and its place in the tab order. It also takes `aria-hidden`, so assistive technology skips it.

`ChannelHeaderTitle` takes `ChannelHeaderIcon` and `ChannelHeaderName` as children and adds a chevron after them. With `as="span"` it renders plain text with no chevron, and assistive technology still reads it.

The registry exports `ChannelHeader`, `ChannelHeaderInfo`, `ChannelHeaderIcon`, `ChannelHeaderName`, `ChannelHeaderDivider`, `ChannelHeaderTopic`, `ChannelHeaderToolbar`, `ChannelHeaderAction`, `ChannelHeaderSearch`, `ChannelHeaderBack`, `ChannelHeaderTitle`, `ChannelHeaderOnline`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

The bar is a `div`. A `header` element outside `main`, `article`, `aside`, `nav` or `section` is a banner landmark, and a page must have only one. Pass `as="header"` when the bar sits inside one of those elements.

Every icon-only action needs an `aria-label`. `ChannelHeaderBack` has no text either. Put the unread count in its label, for example "Back to channels, 3 unread", because the label replaces the badge for assistive technology.

Set `active` on an action that turns something on and off. The button then reports its state with `aria-pressed`. Keep the label the same in both states, for example "Member list".

`ChannelHeaderSearch` takes its accessible name from its text, so the name always matches what a user sees. The same holds for `ChannelHeaderTitle`, whose name is the channel name.

Do not hide an interactive action with `aria-hidden` alone. It stays in the tab order, and a keyboard user lands on a control that a screen reader cannot announce. Use the decorative form.
