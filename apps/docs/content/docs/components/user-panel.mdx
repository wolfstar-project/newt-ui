Use it once per screen, pinned to the bottom of the navigation column, for the controls that belong to the person and not to the page: mute, deafen, open settings. It is the place a reader looks to check which account they are in.

Compose it from an avatar, `UserPanelInfo` and a `UserPanelActions` row of `UserPanelButton`s.

`UserPanel` is a labelled region and `UserPanelActions` a plain row. Both take the attributes of the element they render.

## Accessibility

The panel is a `<section>` named "User controls"; pass `aria-label` to rename or translate it. Every button is named by its `label`, since an icon alone says nothing to a screen reader. A switch carries `aria-pressed`, and when it is on the icon is struck through as well as turned red, so muted and unmuted differ in shape. Name a switch for what it does ("Mute") and let the pressed state say whether it is on; do not swap the label to "Unmute".
