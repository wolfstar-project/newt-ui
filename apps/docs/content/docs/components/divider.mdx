A rule between two groups of content, with an optional label in its centre. Use it for the date line in a message list or between sections of a dense panel.

It is built on [Radix Separator](https://www.radix-ui.com/primitives/docs/components/separator) in React and [Reka UI Separator](https://reka-ui.com/docs/components/separator) in Vue. The primitive sets the role and the orientation. The look comes from `dividerVariants`.

`Divider` renders a `<div>` and accepts its native attributes. React uses `className`, while Vue uses `class`. `dividerVariants` gives the same classes to an element of your own.

## Accessibility

The divider has `role="separator"`. A vertical divider also has `aria-orientation="vertical"`. A screen reader announces the separator and can ignore its content. If the label carries meaning, such as a date, repeat it in an `aria-label` on the divider. Set `decorative` when the rule only adds space, and the divider leaves the accessibility tree.
