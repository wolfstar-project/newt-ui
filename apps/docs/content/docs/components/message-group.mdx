## Examples

### Message list

Set `as="li"` to render each row as an item of the list that holds the channel, so assistive technology announces how many messages there are.

<ComponentPreview name="message-group" variant="list" />

### App tags

`MessageGroupBotTag` marks an author as an application. On its own it reads "BOT", `verified` adds a check, and its content and `aria-label` replace the label and the accessible name.

The registry exports `MessageGroup`, `MessageGroupAvatar`, `MessageGroupReply`, `MessageGroupBody`, `MessageGroupHeader`, `MessageGroupAuthor`, `MessageGroupBotTag`, `MessageGroupTime`, `MessageGroupContent`, `MessageGroupReactions`, `MessageGroupEphemeralNotice`, `MessageGroupEphemeralAction`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Preserve the native semantics of the rendered elements and pass through ARIA attributes when the surrounding context needs a label or description. Any interactive child needs a visible focus indicator, and meaning must not rely on colour alone.
