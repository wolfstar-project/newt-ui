A select for one value from a list: a trigger, a keyboard-driven listbox and a panel that flips when it runs out of room. This is the option picker from the client, not a styled `<select>`. Each option can carry an icon, a description and a note.

It is built on [Radix Select](https://www.radix-ui.com/primitives/docs/components/select) in React and [Reka UI Select](https://reka-ui.com/docs/components/select) in Vue. The primitive owns the open state, the keyboard, typeahead and the placement. The component adds the look, the option model and the 25-option cap of a message select.

## Usage

<Usage name="select-menu" />

Pass the choices as `options`. In React, control the value with `value` and `onValueChange`, or pass `defaultValue`. In Vue, bind `v-model`, or pass `default-value`.

## Examples

### Placeholder

With no value, the trigger shows the `placeholder` in muted text until an option is picked. Options need only a `value` and a `label`.

<ComponentPreview name="select-menu" variant="placeholder" />

### Message variant

`variant="message"` is the select attached to a message. The list is capped at 25 options and its scrollbar is always visible. No row keeps a tick, because the choice is submitted and not kept.

<ComponentPreview name="select-menu" variant="message" />

### Disabled

`disabled` locks the trigger while still showing the option in force, including its `note`.

<ComponentPreview name="select-menu" variant="disabled" />

In React, `icon` is a node. In Vue, `icon` is a component. The root also accepts the native attributes of a `<div>`, and a `className` (`class` in Vue) that is merged with the defaults.

## Accessibility

The trigger is a `combobox` with `aria-expanded` and, while the panel is open, `aria-controls` pointing at it. The panel is a `listbox`, and both take their name from `label`. Each option carries `aria-selected`, and its description is linked with `aria-describedby`.

`Enter`, `Space`, `Up` and `Down` open the list. Focus moves to the selected option, or to the first option. `Up` and `Down` move through the options and skip disabled ones. `Home` and `End` jump to the ends. Typing a letter moves to the next option whose label starts with it. `Enter` or `Space` selects the focused option and returns focus to the trigger. `Escape` closes the list and returns focus to the trigger, and so does a press outside.

While the list is open, the page behind it does not scroll and does not take pointer events. Inside a drawer or a modal, `Escape` closes the list first and the dialog on the next press.
