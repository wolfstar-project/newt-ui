---
title: "Number Input"
description: "A number field with decrement and increment buttons that respect min, max and step."
---

Use it when the number itself is what the reader is setting: a slowmode in seconds, a member limit, a retry count. The steppers are real buttons large enough for a finger, and the field between them still takes typing.

What is typed is kept as text until it reads as a number, so the field can be cleared on the way to a new value. A value outside the range is pulled back in when the field is left.

Every other attribute is passed to the number input. `className` (React) or `class` (Vue) lands on the wrapper, which is where a width belongs.

## Accessibility

The field is a native `<input type="number">`, so it is announced as a spin button with its range, and `Up` and `Down` step it without the buttons. The two buttons are named by `decrementLabel` and `incrementLabel`; translate them with the rest of the interface. Name the field itself with a `<label>` or `aria-label`, and say the unit in the label or the helper text, because "15" alone does not say seconds.
