## Usage

<Usage name="channel-welcome" />

`ChannelWelcomeAction` is a button. Pass `href` to make it a link, or pass a router link component to `as`.

A showcase or a read-only view draws the action and does nothing with it. Pass `as="span"` for that case. The action keeps its look and loses its pointer, its hover and its place in the tab order. It also takes `aria-hidden`, so assistive technology skips it.

The registry exports `ChannelWelcome`, `ChannelWelcomeIcon`, `ChannelWelcomeTitle`, `ChannelWelcomeDescription`, `ChannelWelcomeAction`, `ChannelWelcomeDate`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Preserve the native semantics of the rendered elements and pass through ARIA attributes when the surrounding context needs a label or description. Any interactive child needs a visible focus indicator, and meaning must not rely on colour alone.

Do not hide an interactive action with `aria-hidden` alone. It stays in the tab order, and a keyboard user lands on a control that a screen reader cannot announce. Use the decorative form.
