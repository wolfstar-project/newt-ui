## Examples

### Accent colors

The `color` prop sets the bar on the leading edge. It takes any CSS colour, so passing a `--newt-*` token lets an embed signal success, a warning or a failure and still follow the theme.

<ComponentPreview name="embed" variant="colors" />

### Fields

`EmbedFields` lays its `EmbedField` children out in a grid that fits as many columns as the width allows. Use it for short name and value pairs, such as stats or settings.

<ComponentPreview name="embed" variant="fields" />

### Minimal

Every part of an embed is optional. A lone `EmbedDescription` is enough for a short confirmation, and with no `color` the bar takes the brand colour.

<ComponentPreview name="embed" variant="minimal" />

The registry exports `Embed`, `EmbedAuthor`, `EmbedAuthorIcon`, `EmbedAuthorName`, `EmbedEyebrow`, `EmbedTitle`, `EmbedDescription`, `EmbedFields`, `EmbedField`, `EmbedFieldName`, `EmbedFieldValue`, `EmbedFooter`, `EmbedFooterIcon`, `EmbedFooterSeparator`, `EmbedTimestamp`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Preserve the native semantics of the rendered elements and pass through ARIA attributes when the surrounding context needs a label or description. Any interactive child needs a visible focus indicator, and meaning must not rely on colour alone.
