## Usage

<Usage name="message-composer" />

The bar holds, in order: the add button, the `leading` controls, the field and the send button. The field holds the input, then the `actions`. Set `showAdd` to `false` (`:show-add="false"` in Vue) to remove the add button.

`Enter` sends the value. The send button is off while the value is empty or holds only spaces. Set `disabled` to turn off the input, the add button and the send button.

### Icon buttons

`messageComposerButtonVariants` gives the style of the built-in icon buttons to a button of your own. Use it for a button in `leading`, `actions` or `trailing`, so it matches the add and send buttons. In the HTML flavour, give the button the class `newt-composer__button`.

```tsx
<MessageComposer
  channelName="general"
  actions={
    <button
      type="button"
      aria-label="Emoji"
      className={messageComposerButtonVariants()}
    >
      <EmojiIcon />
    </button>
  }
/>
```

## Examples

### Your own field

`renderInput` in React and the `#input` slot in Vue replace the built-in input. The composer keeps its value, its keyboard handling and the state of the send button. The function or the slot receives:

- `value`: the current value.
- `setValue`: changes the value, as typing does.
- `submit`: sends the value, as `Enter` does.
- `disabled`: whether the composer is off.
- `inputProps`: the placeholder, the label, the combobox attributes, `disabled` and the keydown handler.

Spread `inputProps` on the element that takes focus: `{...inputProps}` in React, `v-bind="inputProps"` in Vue. The keydown handler is `onKeyDown` in React and `onKeydown` in Vue. The field here draws the command as a chip and keeps a plain input for the last option.

<ComponentPreview name="message-composer" variant="input" />

### Narrow layout

Set `layout="narrow"` on a phone. The bar loses its frame, the field becomes a pill, and the buttons beside the field become circles. The composer does not pick the layout from its width, so a composer in a narrow sidebar keeps the default bar. Choose the layout from the width of the screen in your app.

Give a button beside the field `messageComposerButtonVariants({ layout: "narrow" })`. A button in `actions` sits inside the pill, so it keeps the default style.

`trailing` takes the place of the send button while the value is empty. The example puts a microphone there, and the send button comes back once there is something to send. `trailing` works in both layouts.

In the HTML flavour, add `newt-composer--narrow` to the bar and `newt-composer__button--narrow` to each button beside the field.

The registry exports `MessageComposer` and `messageComposerButtonVariants`, and the types `MessageComposerInputProps` and `MessageComposerInputAttributes`. The root renders a `<div>` and accepts its native attributes. React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

The bar is a `group` named after the channel. The field takes its accessible name from the placeholder, so keep the channel in it.

The bar, the field, the add button and the send button take their names from `labels`. [Translating labels](/docs/translating-labels) lists every English default.

A field of your own must take focus and carry `inputProps`, so it keeps the label, the combobox attributes and the keyboard handling. If the field is not an `<input>`, set its `aria-disabled` from `disabled`.

Give every icon button you add an `aria-label`. A button in `trailing` replaces the send button while the value is empty, so name it after what it does.
