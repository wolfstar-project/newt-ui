A bar that fills from the start edge as a task advances. Use it for uploads, server boosts and other work that has a known end.

It is built on [Radix Progress](https://www.radix-ui.com/primitives/docs/components/progress) in React and [Reka UI Progress](https://reka-ui.com/docs/components/progress) in Vue. The primitive sets the role and the value attributes. `ProgressLabel` is a plain row for the text above the bar.

## Examples

### Variants

`success` for something that finished and `danger` for a limit about to be reached; the default gradient is for work still going on. The visible label sits outside the bar, so each bar repeats it as its `aria-label`.

<ComponentPreview name="progress" variant="variants" />

### A custom maximum

Set `max` to count in the thing's own unit, such as 3 boosts of 7, instead of working out a percentage by hand.

<ComponentPreview name="progress" variant="max" />

### Controlled

The bar holds no state: it draws the `value` it is given and eases to the next one. Here the variant changes to `success` when the value reaches the end.

`Progress` renders a `<div>` with the filled part inside it. The bar carries `data-state`, which is `loading` below `max` and `complete` at `max`. `ProgressLabel` is a `<div>` and accepts its native attributes. `progressVariants` gives the gradient classes to an element of your own.

## Accessibility

The bar has `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`. It also has `aria-valuetext`, which is the result of `getValueLabel`. The bar has no name of its own. Give it an `aria-label`, or an `aria-labelledby` that points at the visible label. The variant colour is not announced, so put a failure or a limit in the text too.
