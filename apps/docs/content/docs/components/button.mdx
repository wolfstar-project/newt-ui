The button carries six intents and five sizes. Which one you reach for is a statement about what the action does, not about how it should look — `danger` is destructive, `success` is confirming, `link` is navigation that happens to sit in a row of buttons.

## Examples

### Sizes

`sm`, `message`, `default` and `lg` change the padding and the text size. `message` is 32px high, the size of a button in a message's action row. `icon` is a circle for a lone glyph. An icon button has no visible text, so give it an `aria-label`.

<ComponentPreview name="button" variant="sizes" />

### Leading and trailing content

Put an icon component or a unicode emoji before the label with `leading`, or after it with `trailing`. In Vue these are the `#leading` and `#trailing` slots. Each sits in its own box, so the button's gap separates it from the label. Hide an emoji with `aria-hidden="true"` when the label already says the action. The `emoji` prop still takes an image URL.

<ComponentPreview name="button" variant="slots" />

### Disabled

`disabled` dims the button and the browser stops it taking clicks or focus. On a link there is nothing native to disable, so the button drops its `href` and sets `aria-disabled` instead.

<ComponentPreview name="button" variant="disabled" />

### As a link

Pass `href` and any variant renders an `<a>`, for an action that goes somewhere. `launchIcon` adds the link-out glyph to a variant that lacks it, and `launchIcon={false}` removes it from `variant="link"` when the destination is on the same site.

Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

It renders a real `<button>`, so `Enter` and `Space` activate it and `disabled` is honoured by the browser rather than emulated. An icon-only button (`size="icon"` with no text) has no visible text: give it an `aria-label`. The focus ring is a 2px `--newt-text-link` outline at 2px offset, and it is not removed on `:focus-visible`.
