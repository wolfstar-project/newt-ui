The registry exports `Reaction`, `ReactionGroup`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

The reaction is a real button and publishes its toggled state through `aria-pressed`. A `readonly` reaction is an image with the same accessible name instead, so a feed that only shows counts adds no tab stops. Translate the name with `formatLabel` when the page is not in English. Keep the emoji name and count understandable to screen readers.
