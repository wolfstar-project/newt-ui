Rendered markdown is the one thing a component library cannot style with
components: what arrives is whatever the renderer emitted. Typeset is a wrapper
and two class names — the rules are the stylesheet `add typeset` appends, and
nothing inside needs a class of its own.

The [builder](/typeset) tunes the three variables live; [the guide](/docs/typeset)
explains what each one does.

## Typeset or Markdown [#which]

Both deal with markdown, at different ends of it.

- **Typeset** styles HTML that something else produced: a remark or
  markdown-it pipeline, MDX, a CMS field, an assistant reply run through a
  markdown library. You keep your renderer; Typeset gives its output the
  library's rhythm.
- **[Markdown](/docs/components/markdown)** takes a chat message as a string,
  parses chat markdown — `<@id>` mentions, `<t:…>` timestamps, `||spoilers||`,
  `-#` subtext — and renders it with the library's own components. Nothing to
  style afterwards, and no Typeset around it.

## What it styles [#markdown]

Typeset never sees markdown — it sees whatever a renderer emitted from it. The
left column is CommonMark and GFM, the middle is the element that reaches the
wrapper, and everything in it is styled by the stylesheet without a class of
its own.

| Markdown                  | Element                       | Notes                                                    |
| ------------------------- | ----------------------------- | -------------------------------------------------------- |
| `#` … `######`            | `<h1>` … `<h6>`               | One display face; sizes are `em` of the base.            |
| `**bold**` / `*italic*`   | `<strong>` / `<em>`           | Bold takes the primary text colour.                      |
| `~~strikethrough~~` (GFM) | `<del>`                       | Falls back to the muted colour.                          |
| `` `inline code` ``       | `<code>`                      | Monospace on the surface colour.                         |
| ` ```lang ` fenced block  | `<pre><code>`                 | Scrolls sideways rather than widening the column.        |
| `[label](url)`, autolinks | `<a>`                         | Link colour, underlined.                                 |
| `![alt](src)`             | `<img>`                       | Never wider than the column.                             |
| `> quote`                 | `<blockquote>`                | Rule on the inline start edge. Holds several paragraphs. |
| `- item` / `1. item`      | `<ul>` / `<ol>`               | Nested lists keep their own counter and a tighter gap.   |
| `- [x] task` (GFM)        | `<li><input type="checkbox">` | The box takes the bullet's place.                        |
| `\| a \| b \|` (GFM)      | `<table>`                     | `:-:` and `--:` columns keep their alignment.            |
| `[^1]` (GFM)              | `<sup>` + `<section>`         | The reference keeps the line; the notes sit apart.       |
| `---`                     | `<hr>`                        | One border-coloured rule.                                |

Raw HTML a renderer passes through is covered too: `<u>`, `<s>`, `<small>`,
`<mark>`, `<kbd>`, `<sub>`/`<sup>`, `<dl>`, `<details>` and `<figure>`.

<Callout>
  Chat syntax is not here on purpose. `||spoiler||` hides content until it is
  clicked, which a class cannot do; a mention or a timestamp is an id that has
  to be resolved. A general renderer does not know any of them — that is what
  [Markdown](/docs/components/markdown) is for. Anything block-level dropped
  into a typeset body — a card, a form, a wider widget — should carry
  `not-typeset` so it keeps its own spacing rather than the surrounding rhythm.
</Callout>

## Accessibility

The wrapper adds no semantics of its own, which is the point: the headings,
lists and tables a renderer emitted keep theirs. Two things the styles do carry
are accessibility decisions rather than taste — the measure exists so a line
does not outrun the eye returning to the next one, and the sizes are `em` so a
reader who has enlarged their default text enlarges all of it.

Mark an island of interface inside the prose with `not-typeset` and it keeps
its own spacing and type.
