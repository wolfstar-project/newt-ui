---
title: "Tag Input"
description: "A text field that keeps what was typed as removable chips."
---

Use it for a short, free-form list: tags on a server listing, blocked words, allowed domains. `Enter` or a comma turns the text into a chip, `Backspace` in an empty field takes the last chip back, and a pasted list is split on commas and new lines. A duplicate is dropped.

When the choices come from a known set, use a [Select Menu](/docs/components/select-menu) or an [Entity Select](/docs/components/entity-select) instead.

Every other attribute is passed to the text input, so `placeholder`, `id` and `aria-describedby` go where a label expects them. Inside a `Field` marked `invalid`, the border follows the field without the prop.

## Accessibility

The text input is the field a label points at; give it an `id` and a `<label>`, or an `aria-label`. Each chip's remove button is a real button with its own name, reached with `Tab` before the input. Tell the reader how to commit a tag in the helper text, because nothing on screen says that `Enter` does it.
