A hover bubble built on [Radix Tooltip](https://www.radix-ui.com/primitives/docs/components/tooltip) in React and [Reka UI Tooltip](https://reka-ui.com/docs/components/tooltip) in Vue. It is a hint, never the only place information lives — a control whose meaning is only in its tooltip is a control with no accessible name.

## Examples

### Icon buttons

The usual place for a tooltip: a button that shows only an icon. Give the button an `aria-label` with the same words, so the label a sighted reader sees on hover is also the name a screen reader announces. Use `asChild` (`as-child` in Vue) on `TooltipTrigger` to put the tooltip on your own button.

<ComponentPreview name="tooltip" variant="toolbar" />

### With a shortcut

`TooltipContent` is a slot. Add `Kbd` after the label to teach the keys that do the same thing.

<ComponentPreview name="tooltip" variant="shortcut" />

### Below the trigger

The label opens above its trigger. Pass `side="bottom"` to `TooltipContent` to open it underneath, for a trigger at the top edge of the window. It flips by itself when there is no room.

Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

The bubble is linked to its trigger with `aria-describedby` while it is open, so it is read as a description rather than as the name. It opens on focus as well as hover, and `Escape` dismisses it. Do not put a control inside a tooltip: it cannot be reached by keyboard.
