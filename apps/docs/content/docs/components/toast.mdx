A transient notification with a status icon, built on [Radix Toast](https://www.radix-ui.com/primitives/docs/components/toast) in React and [Reka UI Toast](https://reka-ui.com/docs/components/toast) in Vue. The primitive owns the behaviour; newt/ui owns the look. It dismisses itself after a timeout, on a swipe, or when the reader closes it.

## Usage

<Usage name="toast" />

Wrap the application in one `ToastProvider` and put one `ToastViewport` inside it. Every `Toast` below the provider is rendered into the viewport, wherever you write the toast. The viewport floats at the bottom inline-end corner of the screen.

The previews on this page pass `static items-start` to `ToastViewport`. Those classes keep the viewport in the page flow, so each toast shows inside its preview.

## Examples

### Variants

`variant` is `success` or `error`, and changes the icon's colour and glyph. Both toasts here set `duration` to `0` and leave out `ToastClose`, so they stay on screen.

<ComponentPreview name="toast" variant="variants" />

### Controlled

Hold `open` yourself to raise a toast in answer to an action. The timer and the close button both report `false` through `onOpenChange` in React, or `update:open` in Vue, which `v-model:open` handles.

<ComponentPreview name="toast" variant="controlled" />

### With an action

Wrap a `Button` in `ToastAction` to offer a way back. The action closes the toast after its own click handler runs. Set `duration` to `0` on a toast like this one: an undo that disappears after five seconds is one most readers miss.

`ToastAction` and `ToastClose` render a button. Pass `asChild` (`as-child` in Vue) to put the behaviour on your own element, such as a `Button`. `ToastIcon` and `ToastContent` are plain elements. `ToastTitle` and `ToastDescription` hold the text a screen reader announces. Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

The primitive announces each toast through a live region, so a screen reader reads the title and the description without a move of focus. The default `type` is `background`, which waits for the screen reader to finish its sentence. The timer pauses while the pointer is over the viewport, while focus is inside it, and while the window is in the background. `F8` moves focus to the viewport, `Tab` then reaches each toast and its buttons, and `Escape` closes the focused toast. A focused toast shows a focus ring. `ToastClose` has the accessible name "Dismiss"; pass `aria-label` to translate it. Do not put the only route to an action in a toast: give `ToastAction` an `altText` that names another route.
