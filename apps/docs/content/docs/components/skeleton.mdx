## Examples

### Variants

`avatar`, `title` and `text` come with a size. `default` has none and takes its shape from the classes you pass, which is how to stand in for an image or a whole block.

<ComponentPreview name="skeleton" variant="variants" />

### In a card

Build the placeholder with the same layout as the content it replaces, so nothing moves when the content arrives.

<ComponentPreview name="skeleton" variant="card" />

### Loading state

Swap the skeleton for the content when it is ready. A skeleton is hidden from screen readers, so set `aria-busy` on the region while it is shown.

<ComponentPreview name="skeleton" variant="loading" />

The registry exports `Skeleton`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Preserve the native semantics of the rendered elements and pass through ARIA attributes when the surrounding context needs a label or description. Any interactive child needs a visible focus indicator, and meaning must not rely on colour alone.
