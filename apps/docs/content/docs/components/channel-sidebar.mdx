The navigation column of a chat-shaped app, assembled from the registry: the server's name, its categories and channels as a [Tree](/docs/components/tree), and the signed-in user's [User Panel](/docs/components/user-panel) pinned to the bottom. The channel list scrolls; the header and the panel stay put.

Give it a height, and pair it with the [Chat window](/docs/components/chat-window) block for a whole screen.

Mute and deafen are local state inside the block, because it has no voice connection to tell. When yours does, copy the block and lift those two values out.

## Accessibility

The column is an `<aside>` named after the server. Inside it the channels are one tab stop with the tree's arrow-key model, and the user panel's buttons follow in the tab order. See the Tree and User Panel pages for the detail of each.
