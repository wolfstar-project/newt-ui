Stacked sections that open under their headings, built on [Radix Accordion](https://www.radix-ui.com/primitives/docs/components/accordion) in React and [Reka UI Accordion](https://reka-ui.com/docs/components/accordion) in Vue. The primitive owns the behaviour; newt/ui owns the look.

Use it for content a reader wants one piece of at a time: a short FAQ, the groups of a settings page, the optional details of a form. If every section should be read, plain headings serve better than making the reader open each one.

## Usage

<Usage name="accordion" />

Give each `AccordionItem` a unique `value`. Put an `AccordionTrigger` and an `AccordionContent` inside it. To open a section at the start, pass its value to `defaultValue` on `Accordion`.

## Examples

### Multiple open

With `type="multiple"` the sections open and close independently, and `defaultValue` takes a list of values. Use it when a reader compares sections. Keep the default `single` for a list of questions.

`AccordionTrigger` renders a button inside an `<h3>`, followed by the chevron. `AccordionContent` renders the panel, which is removed from the page while the section is closed. Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

Each trigger is a button inside a heading and carries `aria-expanded` and `aria-controls` for its panel. The panel is a `role="region"` named by its trigger. `Enter` and `Space` toggle a section. `Tab` moves between triggers, and so do the Down and Up arrow keys, `Home` and `End`. A disabled trigger is dimmed and takes no focus. Write a title that makes sense alone, because a screen reader user moves through the titles before opening any. The chevron is decoration, turns a quarter when the section is open, and is mirrored in right-to-left text.

A closed panel is not in the page, so find-in-page does not match text inside it. In Vue, pass `:unmount-on-hide="false"` to `Accordion` to keep closed panels in the page; a find-in-page match then opens the section.
