A pill tab group built on [Radix Tabs](https://www.radix-ui.com/primitives/docs/components/tabs) in React and [Reka UI Tabs](https://reka-ui.com/docs/components/tabs) in Vue. The primitive owns the behaviour; newt/ui owns the look. The panel is only rendered for the active tab, so a tab whose content is expensive does not cost anything until it is opened.

## Examples

### Controlled

Hold the active tab yourself with `value` and `onValueChange` in React, or `v-model` in Vue, when something outside the list has to read it or change it. Here the link below the tabs switches to Pending.

<ComponentPreview name="tabs" variant="controlled" />

### With panels

`Tabs` shares the state, `TabsList` holds the triggers, and each `TabsContent` sits beside the list, not inside it. Each `TabsContent` renders only while its trigger is active.

<ComponentPreview name="tabs" variant="panels" />

### Disabled tab

A trigger is a native button and takes `disabled`. The trigger dims itself and leaves the arrow-key order.

<ComponentPreview name="tabs" variant="disabled" />

## Accessibility

It implements the tabs pattern: `TabsList` is the `role="tablist"`, `aria-selected` on the triggers, `aria-controls` and `aria-labelledby` linking each pair. Only the active trigger is in the tab order; `Left` and `Right` move between triggers, `Home` and `End` jump to the ends.
