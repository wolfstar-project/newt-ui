## Examples

### Labels only

`DropdownIcon` and `DropdownDescription` are optional. A label alone makes a compact action menu; give the destructive action the danger colour and keep it last, below a divider.

<ComponentPreview name="dropdown" variant="simple" />

### Selected item

`active` highlights one item. The menu keeps no state, so hold the value yourself and set it from each item's click; `role="menuitemradio"` with `aria-checked` tells a screen reader that one item is chosen.

<ComponentPreview name="dropdown" variant="status" />

### Opened from a button

The panel does not open or position itself. Toggle it from a button that carries `aria-haspopup` and `aria-expanded`, place it against a `relative` wrapper, and close it when an item is chosen or Escape is pressed.

## API reference

The registry exports `Dropdown`, `DropdownItem`, `DropdownIcon`, `DropdownContent`, `DropdownLabel`, `DropdownDescription`, `DropdownDivider`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Connect the trigger and menu with `aria-controls` and `aria-expanded`, support arrow keys and `Escape`, and return focus to the trigger on close.
