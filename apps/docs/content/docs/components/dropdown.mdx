---
title: "Dropdown Menu"
description: "A menu that opens from a button, with icon, label and description items that highlight in brand color."
---

Use it for a list of actions that belong to one button: a server menu, the actions for a channel, a status picker. For a few controls or a short explanation use a [Popover](/docs/components/popover), and for a menu that opens on a right click use a [Context Menu](/docs/components/context-menu).

It is built on [Radix Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu) in React and [Reka UI Dropdown Menu](https://reka-ui.com/docs/components/dropdown-menu) in Vue. The primitive owns the behaviour; newt/ui owns the look. The menu opens below its trigger and start-aligned unless `side` and `align` say otherwise, and it flips when it would leave the viewport.

## Usage

<Usage name="dropdown" />

`DropdownTrigger` is a plain button that carries the state and has no look of its own. Give it the classes of the button it should be (`buttonVariants({ variant: "secondary" })` in the example), or use `asChild` (`as-child` in Vue) to put the state on your own button.

An item holds a `DropdownIcon`, then a `DropdownItemText` with a `DropdownItemLabel` and a `DropdownItemDescription`. Listen to `onSelect` (`@select` in Vue) for the choice. The menu closes after a choice; call `event.preventDefault()` in the handler to keep it open.

## Examples

### Labels only

`DropdownIcon` and `DropdownItemDescription` are optional. A label alone makes a compact action menu. Give the destructive action `variant="danger"` and keep it last, below a `DropdownSeparator`.

<ComponentPreview name="dropdown" variant="simple" />

### One choice

`DropdownRadioGroup` holds one value, and each `DropdownRadioItem` names its own. The checked item keeps the brand fill, and a screen reader hears it as a checked radio item.

<ComponentPreview name="dropdown" variant="status" />

### Your own button, groups and controlled state

`asChild` puts the menu state on a `Button`. `DropdownGroup` with a `DropdownLabel` names a set of items. Control the menu with `open` and `onOpenChange` in React, or `v-model:open` in Vue.

The registry exports `Dropdown`, `DropdownTrigger`, `DropdownContent`, `DropdownGroup`, `DropdownLabel`, `DropdownItem`, `DropdownRadioGroup`, `DropdownRadioItem`, `DropdownSeparator`, `DropdownIcon`, `DropdownItemText`, `DropdownItemLabel`, `DropdownItemDescription` and `dropdownItemVariants`. Parts without a table accept the props of the primitive part or the native element they render. React uses `className`; Vue uses `class` and fallthrough attributes.

## Accessibility

The trigger carries `aria-haspopup="menu"`, `aria-expanded` and, while the menu is open, `aria-controls` pointing at it. The panel is a `role="menu"` named by its trigger. Items are `role="menuitem"`, and radio items are `role="menuitemradio"` with `aria-checked`. `DropdownGroup` is a `role="group"`; put a `DropdownLabel` inside it as its heading. `DropdownIcon` is hidden from screen readers, so the label must carry the meaning.

`Enter`, `Space` or `ArrowDown` on the trigger opens the menu and moves focus into it. The arrow keys, `Home` and `End` move between items. A typed letter moves to the next item that starts with it. `Enter` or `Space` chooses the focused item. `Escape` closes the menu, and so does a press outside. Focus returns to the trigger when the menu closes.
