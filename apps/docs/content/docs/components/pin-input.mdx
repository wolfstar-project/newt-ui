---
title: "Pin Input"
description: "A short code entered one character to a box, for two-factor and verification codes."
---

Use it for a code of known length that somebody reads off another screen: a two-factor code, an email verification code, a pairing code. Typing fills a box and moves on, `Backspace` steps back, and a pasted code is dealt out across the boxes.

The value is a single string with no gaps, so a character typed in a later box lands in the first empty one.

Submit from the complete callback when the code should be checked as soon as it is whole, and keep a visible button for readers who paste a code and expect to confirm it.

## Accessibility

The boxes sit in a `role="group"` named by `label`, and each box announces its position ("Digit 2 of 6"). The first box carries `autocomplete="one-time-code"`, which lets a phone offer the code from a text message. `Left` and `Right` move between boxes following the reading direction, and `Home` and `End` jump to the ends. An error needs words as well as the red border: put the message in a `FieldHelp` with `variant="error"`.
