An image, or the initials that stand in for one. Three sizes, all circles, all sized in the same steps the rest of the library uses.

It is built on [Radix Avatar](https://www.radix-ui.com/primitives/docs/components/avatar) in React and [Reka UI Avatar](https://reka-ui.com/docs/components/avatar) in Vue. The primitive tracks the image. `AvatarFallback` shows while the image loads and when the load fails.

## Examples

### With an image

`AvatarImage` fills the circle at every size and is cropped to it. Give it an `alt` when the avatar stands on its own.

<ComponentPreview name="avatar" variant="image" />

### Initials

`AvatarFallback` centres initials when there is no image. The fill is the brand colour unless a token utility on the avatar says otherwise; a lone avatar takes `role="img"` and an `aria-label`, because initials are not a name.

<ComponentPreview name="avatar" variant="fallback" />

### Beside a name

Next to a visible name the avatar is decoration: the image takes `alt=""` and the initials are hidden from screen readers, so the name is read once.

<ComponentPreview name="avatar" variant="with-name" />

`Avatar` and `AvatarFallback` render a `<span>`. `AvatarImage` renders an `<img>`. Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced. `avatarVariants` gives the same classes to an element of your own.

## Accessibility

An avatar next to a name is decorative: the name is the accessible name, so `alt=""` is correct and repeating it is noise. An avatar that stands alone (a stack of participants, an author with no byline) needs a real `alt`. An avatar that shows only initials needs `role="img"` and an `aria-label` on `Avatar`. If the image can fail, give `Avatar` the name, because the fallback initials are not a name.
