The picker for the things a server already knows about: its members, its roles, its channels, or all of them at once. It is a separate control from the [string select](/docs/components/select-menu), because the rows are not strings. A member arrives with a face, a role with a colour and a headcount, and a channel with the glyph of its kind.

The panel is built on [Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover) in React and [Reka UI Popover](https://reka-ui.com/docs/components/popover) in Vue. The primitive owns the placement, the portal, `Escape` and the press outside. The listbox inside the panel is newt/ui's own, because Radix has no listbox that takes more than one value.

## More than one [#multiple]

`max` above one turns the control into chips. The choices leave the list and sit in the trigger, each with a cross. Every row shows a box and not a tick: the shape says that a new choice keeps the earlier ones. `Backspace` removes the last chip.

At the limit the list stays open and takes no more choices. It does not drop the oldest choice, because somebody picked it.

## Usage

<Usage name="entity-select" />

Pass the entities as `options`. The value is always an array, also when `max` is one. In React, control it with `value` and `onValueChange`, or pass `defaultValue`. In Vue, bind `v-model`.

## Accessibility

The trigger is a `combobox` with `aria-haspopup="listbox"` and `aria-expanded`. While the panel is open, `aria-controls` points at the `listbox`, which carries `aria-multiselectable` when `max` is above one. Both take their name from `label`. Each option carries `aria-selected`.

Focus stays on the trigger while the list is open. `aria-activedescendant` names the option the keyboard is on. `Enter`, `Space`, `Up` and `Down` open the list. `Up` and `Down` move through the options and skip disabled ones. `Home` and `End` jump to the ends. `Enter` or `Space` picks the active option. With `max` at one the list then closes. `Escape` closes the list, and so does a press outside. Inside a drawer or a modal, `Escape` closes the list first and the dialog on the next press.

A chip is not a button, because it sits inside the trigger. A pointer removes a chip with a press on it. The keyboard removes the last chip with `Backspace` while the list is closed. A role's colour is decoration: the name of the role is always shown as text.
