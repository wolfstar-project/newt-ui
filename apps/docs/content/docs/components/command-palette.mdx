---
title: "Command Palette"
description: "A searchable quick switcher of grouped destinations and actions, driven from the keyboard."
---

Use it to give keyboard users one place to jump anywhere or run anything: switch channel, open settings, mention a member. It complements the visible navigation and never replaces it, because nothing on screen says the palette exists. Bind it to a shortcut and offer a button too.

Typing narrows the list to the rows whose label, description or `keywords` contain the query. The palette filters the rows it is given; for results from a server, pass new `groups` as the query changes.

Opening the palette always starts from an empty query with the first row highlighted.

## Accessibility

The shell is a native `<dialog>`, so focus is held inside it and `Escape` closes it. The search field is a `role="combobox"` that keeps focus the whole time: `Up` and `Down` move the highlight, wrapping at the ends, and `aria-activedescendant` tells a screen reader which row is highlighted. `Enter` chooses it. Rows are `role="option"` inside a `role="listbox"`, grouped under their headings. The footer hints repeat what the keys do for sighted users and are hidden from assistive technology.
