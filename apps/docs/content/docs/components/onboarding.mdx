A wizard for a task with a few fixed stages, assembled from a [Stepper](/docs/components/stepper) and two buttons: creating a server, connecting a bot, a first-run setup. The block owns the order and the navigation; what each step asks is yours.

The content is a function of the step's index in React and a scoped slot in Vue. Set `canContinue` to false while the current step is incomplete and the forward button waits.

Keep each step's answers in your own state, as the example does, so going back shows what was entered.

## Accessibility

Moving to another step moves focus to that step's heading, so a screen reader starts from the new content instead of staying on a button whose label just changed. The stepper marks the step in progress with `aria-current="step"`. A disabled forward button gives no reason, so say what is missing near the field that needs it. Give the block an `aria-label` naming the task.
