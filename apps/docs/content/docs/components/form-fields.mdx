Form fields are the inputs, textareas, selects, labels, helper text, switches and checkboxes of a form, styled for the newt/ui dark theme. Compose a form from the exported parts.

Three parts are built on Radix primitives in React and Reka UI primitives in Vue. `Label` is on Label ([Radix](https://www.radix-ui.com/primitives/docs/components/label), [Reka UI](https://reka-ui.com/docs/components/label)). `Switch` is on Switch ([Radix](https://www.radix-ui.com/primitives/docs/components/switch), [Reka UI](https://reka-ui.com/docs/components/switch)). `Checkbox` is on Checkbox ([Radix](https://www.radix-ui.com/primitives/docs/components/checkbox), [Reka UI](https://reka-ui.com/docs/components/checkbox)). `Field`, `Input`, `Textarea`, `Select` and `FieldHelp` are native elements.

## Examples

### Validation error

Set `invalid` on the `Field` and every control inside it takes the danger border; swap the help line to `variant="error"` so the message is announced as well as coloured. Type a valid channel name to see both clear.

<ComponentPreview name="form-fields" variant="error" />

### Textarea

`Textarea` shares the input's styling and resizes vertically. Pair it with a `FieldHelp` when the text has a limit the reader should see coming.

<ComponentPreview name="form-fields" variant="textarea" />

### Native select

`Select` is the browser's own `<select>` in the field's clothes: use it for a short list in a dense form, and reach for [Select Menu](/docs/components/select-menu) when options need icons or descriptions.

<ComponentPreview name="form-fields" variant="select" />

### Switch and checkbox

A `Switch` is for a setting that applies the moment it is flipped, a `Checkbox` for an answer submitted with the rest of the form. Both take `disabled`, and both are buttons that need a name from `aria-labelledby` or `aria-label`.

The registry exports `Field`, `Label`, `Input`, `Textarea`, `Select`, `FieldHelp`, `Switch`, `Checkbox`. `Label`, `Switch` and `Checkbox` accept the other props of the primitive they wrap. The other parts accept the native attributes of the element they render. React uses `className`. Vue uses `class` and fallthrough attributes.

## Accessibility

Associate every control with a visible label. `Label` renders a native `<label>`: point `htmlFor` (`for` in Vue) at the `id` of the control. Connect help or error text with `aria-describedby`, and pair invalid styling with `aria-invalid` so the state does not depend on colour alone.

`Switch` is a button with `role="switch"`, and `Checkbox` is a button with `role="checkbox"`. Both carry `aria-checked`, and <kbd>Space</kbd> toggles them. Give each one a name with a `Label`, `aria-labelledby` or `aria-label`. A focused `Switch` shows the browser focus ring, and a focused `Checkbox` takes the `--newt-brand` border.
