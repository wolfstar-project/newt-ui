A radio group is for a choice that is short enough to show in full. A
[select menu](/docs/components/select-menu) hides its options until asked. A
radio group shows all of them at once. The client's settings panels use it when
there are two or three options and the difference between them matters.

It is built on [Radix Radio Group](https://www.radix-ui.com/primitives/docs/components/radio-group)
in React and [Reka UI Radio Group](https://reka-ui.com/docs/components/radio-group)
in Vue. The primitive owns the value, the keyboard and the form input.

The state is in the ring and the dot, not in motion: the selected row reads as
selected in a screenshot, and in greyscale.

## Usage

<Usage name="radio" />

The group owns the value; each `Radio` only names the value it stands for. Leave
`value` off the group and it manages its own selection from `defaultValue`.

<div data-framework="react">

```tsx
<RadioGroup label="Input mode" value={mode} onValueChange={setMode}>
  <Radio value="voice-activity">Voice Activity</Radio>
  <Radio value="push-to-talk">Push to Talk</Radio>
</RadioGroup>
```

</div>

<div data-framework="vue">

```vue
<RadioGroup v-model="mode" label="Input mode">
  <Radio value="voice-activity">Voice Activity</Radio>
  <Radio value="push-to-talk">Push to Talk</Radio>
</RadioGroup>
```

</div>

## Second lines

A choice that needs a sentence to explain it takes a `description`, which sits
under the label in muted text. Use it when the label alone would make somebody
guess; leave it off when it would only restate the label.

## Accessibility

The group has `role="radiogroup"` and an accessible name. Each row is a button
with `role="radio"` and `aria-checked`. The label and the description are inside
the button, so they are its accessible name.

The group is **one tab stop**. <kbd>Tab</kbd> moves focus to the selected row,
or to the first row when nothing is selected. The arrow keys move the selection
and wrap at the ends. They skip disabled rows.

<kbd>Home</kbd> and <kbd>End</kbd> move focus to the first and last enabled row,
and <kbd>Space</kbd> selects the focused row.

Give the group a `label`. Without one, a screen reader does not say what the
choice is for. A focused row shows a 2px `--newt-text-link` outline.
