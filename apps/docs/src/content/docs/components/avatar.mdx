Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

An avatar next to a name is decorative: the name is the accessible name, so `alt=""` is correct and repeating it is noise. An avatar that stands alone — a stack of participants, an author with no byline — needs a real `alt`.
