Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

The bubble is linked to its trigger with `aria-describedby`, so it is read as a description rather than as the name. It opens on focus as well as hover, and `Escape` dismisses it. Do not put a control inside a tooltip: it cannot be reached by keyboard.
