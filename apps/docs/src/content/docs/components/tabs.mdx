Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

It implements the tabs pattern: `role="tablist"`, `aria-selected` on the triggers, `aria-controls` and `aria-labelledby` linking each pair. Only the active trigger is in the tab order; `Left` and `Right` move between triggers, `Home` and `End` jump to the ends.
