The registry exports `UserProfile`, `UserProfileBanner`, `UserProfileHead`, `UserProfileActions`, `UserProfileAvatar`, `UserProfileName`, `UserProfileHandle`, `UserProfileDivider`, `UserProfileBody`, `UserProfileSectionLabel`, `UserProfileBio`, `UserProfileRoles`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Preserve the native semantics of the rendered elements and pass through ARIA attributes when the surrounding context needs a label or description. Any interactive child needs a visible focus indicator, and meaning must not rely on colour alone.
