The registry exports `Field`, `Label`, `Input`, `Textarea`, `Select`, `FieldHelp`, `Switch`, `Checkbox`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Associate every control with a visible label. Connect help or error text with `aria-describedby`, and pair invalid styling with `aria-invalid` rather than colour alone.
