## Accessibility

The dialog carries `role="dialog"` and `aria-modal="true"`, traps focus while it is open, returns focus to whatever opened it, and closes on `Escape`. The content behind it is inert. Give `ModalHeader` real text: it is what a screen reader announces when the dialog opens.
