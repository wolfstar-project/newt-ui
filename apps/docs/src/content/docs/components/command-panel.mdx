The registry exports `CommandPanel` plus the `CommandPanelCommand` and `CommandPanelOption` types. It also accepts the native section attributes; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

The suggestion list is one keyboard focus stop. Arrow keys, Home and End move its active descendant while the detail card is announced through a polite live region. Give the list a contextual `listLabel`, keep command IDs unique, and do not communicate the active command by colour alone.
