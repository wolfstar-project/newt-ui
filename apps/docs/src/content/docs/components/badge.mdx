A small pill for a count, a state or a label. The `dot` variant puts a filled circle before the text, which is how a status reads at a glance without relying on the pill's colour alone.

Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

A badge is text, not a control. If it reports something that changes — an unread count, a build status — put it in a container with `aria-live="polite"` so the change is announced. Never let the colour be the only difference between two states: the words in the badge should differ too.
