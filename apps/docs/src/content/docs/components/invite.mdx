The registry exports `Invite`, `InviteEyebrow`, `InviteBody`, `InviteIcon`, `InviteInfo`, `InviteName`, `InviteCounts`, `InviteCount`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Use descriptive alternative text for a meaningful server image and an empty `alt` for a decorative one. The join action must remain a real button.
