The registry exports `ContextMenu`, `ContextMenuItem`, `ContextMenuShortcut`, `ContextMenuDivider`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

Open the menu from both pointer and keyboard input, move focus into it, support arrow-key navigation, and restore focus to the trigger when it closes.
