The registry exports `AppLauncher`, `AppLauncherHandle`, `AppLauncherHeader`, `AppLauncherBack`, `AppLauncherSearch`, `AppLauncherSearchInput`, `AppLauncherBody`, `AppLauncherSection`, `AppLauncherSectionHeader`, `AppLauncherSectionTitle`, `AppLauncherViewMore`, `AppLauncherList`, `AppLauncherItem`, `AppLauncherItemIcon`, `AppLauncherRecents`, `AppLauncherRecent`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.
