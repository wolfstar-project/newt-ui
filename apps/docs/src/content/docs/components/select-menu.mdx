A complete combobox: a trigger, a search field, a keyboard-driven listbox and a panel that flips when it runs out of room below. This is the option picker from the client, not a styled `<select>`.

Every part also accepts the native attributes of the element it renders, and a `className` that is merged rather than replaced.

## Accessibility

The trigger is a `combobox` with `aria-expanded` and `aria-controls`; the panel is a `listbox` whose options carry `aria-selected`. `Up` and `Down` move the active option, `Home` and `End` jump to the ends, `Enter` selects, `Escape` closes and returns focus to the trigger. The active option is tracked with `aria-activedescendant`, so focus never leaves the trigger.
