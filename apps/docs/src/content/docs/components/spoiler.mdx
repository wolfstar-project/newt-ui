The registry exports `Spoiler`. Parts without a table accept the native attributes for the element they render; React uses `className`, while Vue uses `class` and fallthrough attributes.

## Accessibility

The reveal control must be keyboard operable and expose its expanded state. Do not place essential instructions only inside hidden spoiler content.
