## Usage

```tsx
import { StatusDot, StatusIndicator } from "@/components/ui/status-indicator"
```

```tsx
<StatusIndicator aria-label="Online">
  <Avatar>A</Avatar>
  <StatusDot status="online" />
</StatusIndicator>
```

## Examples

### Statuses

`StatusDot` accepts `status` of `online`, `idle`, `dnd`, `offline` (default) or `streaming`. The online dot renders a pulsing presence ring, which is disabled when the user prefers reduced motion.

```tsx
<StatusDot status="idle" />
<StatusDot status="dnd" />
<StatusDot status="streaming" />
```
