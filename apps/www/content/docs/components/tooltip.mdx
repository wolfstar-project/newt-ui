## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx
<Tooltip>
  <TooltipTrigger>
    <button aria-describedby="help-tip">?</button>
  </TooltipTrigger>
  <TooltipContent id="help-tip">Tooltip text</TooltipContent>
</Tooltip>
```

The tooltip is CSS-driven: it fades in while the wrapper is hovered or contains focus. Link the trigger to the content with `aria-describedby` for screen readers.
