## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<div className="flex gap-3">
  <Skeleton variant="avatar" />
  <div className="flex flex-1 flex-col gap-1.5">
    <Skeleton variant="title" />
    <Skeleton variant="text" className="w-[80%]" />
  </div>
</div>
```

## Examples

### Variants

`variant` accepts `"text"` (14px tall), `"avatar"` (40px circle), `"title"` (20px tall, 40% wide) or `"default"` (size it yourself with `className`). Animation is disabled automatically when the user prefers reduced motion.
