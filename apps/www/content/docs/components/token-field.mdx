
```tsx
<Label htmlFor="bot-token">Bot token</Label>
<TokenField id="bot-token" value={token} />
```

## Behaviour

- The value is rendered in a `password` input until **Reveal** is pressed; the button toggles to **Hide**.
- **Copy** writes the value to the clipboard and shows **Copied!** for 1.5 seconds (configurable via `copiedDuration`).
- Button labels can be customised with `revealLabel`, `hideLabel`, `copyLabel` and `copiedLabel`.
