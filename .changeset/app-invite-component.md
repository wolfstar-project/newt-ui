New `app-invite` component: the app directory card a link to an app unfurls into inside a message, with a cover banner, the app's icon and name, an optional description and a full-width call to action. Available for React, Vue and HTML/CSS (`newtui add app-invite`).

The HTML `.newt-btn` no longer underlines when it is an `<a>`, matching the React and Vue buttons.
