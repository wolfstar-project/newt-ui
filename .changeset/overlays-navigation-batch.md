Add six components to the HTML and CSS distribution: `accordion`, `breadcrumb`, `stepper`, `popover`, `drawer` and `command-palette`. The drawer and the command palette are built on the native `<dialog>` element and the accordion on `<details>`, so focus trapping, Escape and single-open behaviour come from the browser. The React and Vue versions are in the registry under the same names.
